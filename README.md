# Computational Structural Analysis of the RANKL M199K Mutation Associated with Osteopetrosis

MSBD 502 – Computational Structural Biology, Meharry Medical College
LaPorchia Davis & Sade Graves

## Project summary

This project compares wild-type (WT) and M199K-mutant human RANKL (PDB 3URF) using three
independent computational methods to ask whether the M199K missense mutation structurally
and energetically destabilizes RANKL:

1. **Structural comparison** (PyMOL / Biopython) – alignment and CA–CA distance comparison
   of residues near position 199 in WT vs. mutant.
2. **PyRosetta ΔΔG_fold** – REF2015 energy function with FastRelax, comparing relaxed WT and
   mutant energies to estimate the mutation's effect on folding stability.
3. **Molecular dynamics** (OpenMM, AMBER14 force field, TIP3P water) – short production runs
   on WT and mutant systems, analyzed with MDAnalysis for RMSD/RMSF.

## Repository structure


## How to run

1. Open `src/RANKL_M199K_Final_Project.ipynb` in Google Colab.
2. One-time setup: in your Google Drive, make a folder named `RANKL_M199K_project` and
   upload `data/RANKL_WT.pdb` and `data/RANKL_M199K.pdb` into it directly through
   drive.google.com. The notebook mounts Drive and reads the files from there, so this only
   needs to be done once (Colab's local disk gets wiped on every disconnect).
3. Run cells top to bottom. All dependencies are installed via `pip` in the first cells
   (no conda environment required). A GPU runtime (Runtime > Change runtime type > T4 GPU)
   is strongly recommended for the molecular dynamics section.
4. Outputs (plots, tables) are written to the same Drive folder and can be copied into
   `results/`.

See `requirements.txt` for the Python packages used (these are installed automatically by
the notebook itself; the file is provided for reference/reproducibility).

## Key result so far

PyRosetta: ddG_fold = E(M199K, relaxed) − E(WT, relaxed) = **+18.8 REU** (positive =
predicted destabilizing), consistent with prior experimental work showing M199K-equivalent
mutants fail to support normal osteoclast formation.

Molecular dynamics RMSD/RMSF results are still being generated and will be added to
`results/` and this README once complete.

## Data source

Structure: RCSB PDB entry [3URF](https://www.rcsb.org/structure/3URF) – crystal structure of
human RANKL complexed with its decoy receptor osteoprotegerin (OPG).
