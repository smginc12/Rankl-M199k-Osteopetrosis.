# Computational Structural Analysis of the RANKL M199K Mutation Associated with Osteopetrosis

MSBD 502, Computational Structural Biology, Meharry Medical College
LaPorchia Davis and Sade Graves

## Project summary

This project compares wild-type (WT) and M199K-mutant human RANKL (PDB 3URF) using three
independent computational methods to ask whether the M199K missense mutation structurally
and energetically destabilizes RANKL:

1. **Structural comparison** (PyMOL and Biopython): alignment and distance comparison of
   residues near position 199 in WT vs. mutant.
2. **PyRosetta ddG_fold**: REF2015 energy function with FastRelax, comparing relaxed WT and
   mutant energies to estimate the effect of the mutation on folding stability.
3. **Molecular dynamics** (OpenMM, AMBER14 force field, TIP3P water): short production runs
   on the WT and mutant systems, analyzed with MDAnalysis for RMSD and RMSF.

## How to run

1. Open `RANKL_M199K_Final_Project.ipynb` in Google Colab.
2. Upload `RANKL_WT.pdb` and `RANKL_M199K.pdb` to the Colab file browser (left panel). Colab
   clears its local files whenever the runtime disconnects, so upload them again after a
   disconnect.
3. Run the cells from top to bottom. All dependencies install through `pip` in the first
   cells, so no conda environment is needed. A GPU runtime (Runtime, Change runtime type,
   T4 GPU) is strongly recommended for the molecular dynamics section.
4. Plots and tables are written to the `rankl_pipeline_output` folder in the Colab file
   browser. Download them before the runtime ends.

See `requirements.txt` for the packages used. The notebook installs them automatically, and
the file is provided for reference.

## Key results

PyRosetta: ddG_fold = E(M199K, relaxed) minus E(WT, relaxed) = **+18.8 REU**. A positive
value predicts a destabilizing mutation.

Molecular dynamics: mean backbone RMSD over the 100 ps production run was **0.78 A for
wild-type** and **0.89 A for M199K**, so the mutant drifts more overall. The per-residue RMSF
plot (`results/rmsd_rmsf_comparison.png`) shows where that flexibility is concentrated.

All three methods point the same direction: M199K is predicted to destabilize RANKL.

## Known issue: residue 199 label on the RMSF plot

PDBFixer and OpenMM renumber residues from 1 when they write the solvated system, so
position 199 of the original PDB appears as residue 38 inside the MD files. As a result, the
dashed residue 199 marker on the RMSF plot (`results/rmsd_rmsf_comparison.png`) is placed at
x = 199 on the renumbered axis and does not line up with residue 199 of the original PDB.
Only the label is affected. The RMSD values, the RMSF curves, and the PyRosetta results are
not.

`RANKL_M199K_Final_Project_2ND.ipynb` contains the fix, which shifts the residue numbers back
to the original PDB numbering (162 to 317). It was added after the project results were
finalized, so the figures and numbers in this repository come from the original notebook.

## Data source

Structure: RCSB PDB entry [3URF](https://www.rcsb.org/structure/3URF), crystal structure of
human RANKL complexed with its decoy receptor osteoprotegerin (OPG).
